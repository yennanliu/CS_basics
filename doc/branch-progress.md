## Definition of done

Enforced mechanically by `script/py_multi_version/verify.py`; a file passes only if:

- at least **3 blocks with real code** — a `pass`/bare-`return` placeholder does not
  count toward the 3
- every real block carries both `# time =` and `# space =` in its header
- no two blocks are identical after comment/whitespace normalisation, which is what
  stops this pass from re-creating the 366 duplicates task 2 has to remove
- the file parses under `ast.parse`
- **added** lines carry no tabs, no trailing whitespace and no py2 constructs, and the
  file ends in exactly one newline. Pre-existing formatting debt is deliberately out
  of scope here — it belongs to task 2

Each new block also gets the house 4-line header (`# V0-N` / `# IDEA :` / `# time =` /
`# space =`) with its own honest complexity, and every solution is run against the
problem's docstring examples plus randomized cross-checks before it counts. Existing
blocks are left byte-for-byte unchanged — the pass is additive.

`verify.py` audits its own checkout by default; set `PMV_WORKTREE` to point it at
another branch's worktree, which is how this doc reports on every wave at once.
