LC Again
the marker that never graduates

README's status column reads 325 AGAIN against 124 OK, and 106 problems carry the marker after twelve or more review passes. Nothing in this repo ever promotes a row, so AGAIN behaves as a permanent tag rather than a verdict — which means a problem you have actually mastered keeps scoring as a gap and keeps being handed back to you. /lc-again is the missing half of that loop.

Why a skill and not a habit

A column that only ever accretes

This is not a style problem. Three pieces of tooling read this column, and a marker that never moves makes all three of them wrong in the same direction.

▧ The ratio is a floor, not a measurement

The readiness guide says it outright: 125 of 136 hard rows carry AGAIN, some after 20+ passes, so the Mastery percentage cannot be read as one.

Cost: the number you would act on is the number you cannot trust.

▤ The planner keeps handing it back

suggest_review.py reads a high pass count on an AGAIN row as difficulty, not progress. A problem you have mastered scores higher the more times you have beaten it.

Fix: a row that graduates leaves the pool.

◌ The derived list goes stale

data/again_problems.txt is generated from README, and was last regenerated in November 2025 — ten months of edits it has not seen.

Rule: the edit and the refresh are one step, not two.

One pass, no branches

Six steps, in order

The steps never reorder and none of them is optional. Pick one to see what it does and the rule that step exists to enforce. 


      

    


    
    

      
What the cell means

      
Three moves, and what must survive them

      

        The column is free text, but three pieces of it are load-bearing. Everything else is
        your own note and is preserved verbatim, typos included.

clean, unaided, all fourpromote — swap the word, keep the stars and notesAGAIN*** (3) → OK*** (3)

          Another pass is the default and the most common outcome. A problem that needed
          one nudge did not graduate. A row marked (not start) has never been
          attempted at all, so a first attempt makes it an ordinary row rather than a promotion.

All four, or it is another pass:

        

          

1  re-derived it yourself, without looking at the old solution

2  can state the INVARIANT it turns on
   (not the steps - the reason the steps are correct)

3  can name the ONE LINE that sets the complexity

4  handled the edges - empty, single element, duplicates, overflow

        

        

          Asking once is correct; interrogating twice is not. Once you answer, your word is
          taken. And if you would rather not answer, the move is another pass — which is
          not a punishment, it is just what the column already says.
        

      

    


    
    

      
Arguments are inferred, not interrogated

      
How to call it

      

        One problem, one re-solve, one decision. It does not bulk-promote.
      

      

        

/lc-again 128 ok
/lc-again 139

I finally got 128, mark it OK
560 came back again
refresh the again list

The guardrails

      
What it will not do

      

        A promotion that is given away is worse than no promotion at all — it turns the
        column into noise in the other direction, and that is harder to notice.
      

      
    
        
  • ×Promote on request alone.Without establishing that you re-derived it unaided, the move is another pass. Saying "mark it OK" is not the same as having earned it.
    • 
        
  • ×Drop the star run.It is the cost record, not the verdict. Promoting is not forgetting what the problem cost, and the readiness cost curve is computed from exactly those stars.
    • 
        
  • ×Tidy a cell's spelling while it is in there.403 spellings exist. Standardising them is a different commit, and doing it invisibly inside an unrelated edit is how a column stops being readable.
    • 
        
  • ×Touch any other cell or row.Not the tags, not the complexity, not the solution links. One row, one cell.
    • 
        
  • ×Write the practice log.That is /lc-log. A practice attempt and a mastery verdict are different records, and this skill says which one you still owe.
    • 
        
  • ×Bulk-promote.There is no batch mode, on purpose. The bar only means something applied one problem at a time.
    • 
      

    


    
    

      
One markdown file, no dependencies

      
Install

      

        SKILL.md is the whole recipe — nothing to build and no network calls,
        so the same source runs on any agent that takes a system prompt. Pick yours.
      


      

        
        
        
        
        
      


      

        
Drop the skill directory into your user-level skills folder and it loads in every repo:

        

          

git clone --depth 1 https://github.com/yennanliu/CS_basics.git /tmp/cs_basics
mkdir -p ~/.claude/skills
cp -r /tmp/cs_basics/.claude/skills/lc-again ~/.claude/skills/

        

        

          Already installed inside this repo at .claude/skills/lc-again/, so a
          clone of CS_basics needs no setup at all. Claude Code matches it on the description,
          or you can call /lc-again by name — the directory name is
          the command.
        

      


      

        
Zip the directory, then Customize → Skills → + → + Create skill → Upload a skill:

        

          

cd .claude/skills && zip -r lc-again.zip lc-again

        

        

          Leave the YAML frontmatter in SKILL.md intact. description is
          what Claude matches your request against when deciding to load the skill on its own.
        

      


      

        
Codex reads AGENTS.md at the repo root automatically. Point it at the skill:

        

          

## Moving a problem's status

When asked to mark a problem solid, graduate an AGAIN marker, or record
another failed pass, follow `.claude/skills/lc-again/SKILL.md`.

        

        
A pointer, not a copy — one source of truth means a fix reaches every agent at once.

      


      

        
Same shape in GEMINI.md, or point at it for a single session:

        

          

gemini -p "Follow the recipe in .claude/skills/lc-again/SKILL.md. \
I re-solved LC 128 unaided today - should it graduate?"

        

      


      

        

          Paste SKILL.md in as the system prompt. It is self-contained and has no
          references/ to carry. For Cursor or Windsurf, put the Codex pointer above
          into a rule file (.cursor/rules/lc-again.mdc or the editor's equivalent).
        

        

          

curl -sL https://raw.githubusercontent.com/yennanliu/CS_basics/master/.claude/skills/lc-again/SKILL.md

        

        

          One caveat away from this repo: steps 4 and 5 run this repo's scripts. The four-question
          bar in step 2 is the part that transfers anywhere.

The rest of the loop

      
Where it fits

      

        /lc-log records that you practised something;
        /lc-again records that it finally stuck. Between them they are what
        suggest review and the
        review plan read to decide what you are owed, and
        what LC Coach is scoring against when it asks whether you
        could do it unaided.
