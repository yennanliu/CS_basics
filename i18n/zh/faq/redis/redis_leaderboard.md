## 🧠 Redis Sorted Set 入門

Redis 的 **Sorted Set** 是一組不重複的字串（例如 user ID 或帳號名稱），每一個都配上一個浮點數的**分數（score）**。整個集合會自動依分數排序。

對排行榜來說：

* **玩家 / 使用者 ID** 就是 **member**。
* **分數（例如積分、擊殺數、評分）**就是 sorted set 裡的 **score**。

## 🧩 可擴展性的幾點注意

* Redis 是**記憶體內**的：非常快，但沒開持久化（RDB/AOF）資料就是易失的。
* 使用者量非常大時，考慮把排行榜**分片（sharding）**，或改用 **Redis Cluster**。
* 如果精確度不是那麼關鍵，可以**批次更新**，或做**近似排行榜**（例如定期同步回資料庫）。
